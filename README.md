# TixGO MERN Full-Stack Application

A full-stack web application built using the MERN stack — MongoDB, Express.js, React.js, and Node.js.

The project is designed as a complete production-ready application, covering frontend development, backend APIs, database integration, authentication, and deployment.

## Tech Stack

### Frontend
- React.js
- JavaScript
- HTML5
- CSS3
- Bootstrap / CSS
- React Router
- Axios

### Backend
- Node.js
- Express.js
- REST API

### Database
- MongoDB
- Mongoose

### Deployment
- Frontend: Vercel
- Backend: Render
- Database: MongoDB Atlas

## Features

- User registration and login
- Authentication and authorization
- RESTful APIs
- MongoDB database integration
- CRUD operations
- Responsive user interface
- Protected routes
- Form validation
- Error handling
- Secure environment variables
- Production deployment
